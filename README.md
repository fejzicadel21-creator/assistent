# Asistent – OŠ Kiseljak

Aplikacija za pripreme, mjesečne planove, dnevnik i individualne programe (Bosanski jezik i književnost).

U ovom repozitoriju **nema ličnih podataka** učenika. Učenici, brojevi telefona roditelja i individualni programi se učitavaju na telefonu iz datoteke `pocetni-podaci.json` i ostaju samo na uređaju.

## Datoteke
- `index.html` – aplikacija
- `manifest.webmanifest`, `sw.js`, `icons/` – instalacija na telefon i rad bez interneta

## Ažuriranje
Nova verzija: *Add file → Upload files*, prevući novi `index.html`, *Commit changes*. Na telefonu se pojavi nakon minut-dva (zatvorite i ponovo otvorite aplikaciju).
